# Тестирование API

Я написал тесты для api приложения для заказа пиццы. Я использовал TypeScript и библиотеку vitest.

В папке `src` находится код взаимодействия с api:

- `clients/OrderClient.ts` - клиент для взаимодействия с api. Хранит все пути, протоколы, валидирует JSON в ответе
- `data/*` - модели для сущностей, используемых сайтом
- `factories/order.ts` - вспомогательные функции для генерации фейковых моделей. Используется библиотека faker
- `schemas/order.ts` - json-схемы для валидации ответа сайта. Используется библиотека zod
- `db.ts`, `db.config.ts` - взаимодействие с базой данных. Используется, чтобы очищать базу данных между тестами

Тесты находятся в папке `tests`:

- `helpers.ts` - вспомогательные функции, которые используются во многих тестах
- `setup.ts` - настройка запуска тестов. В частности, настраивается очистка базы данных перед каждым тестом, чтобы
  каждый тест работал в чистом окружении
- всё остальное - тесты, разбитые по функциональности сайта

При построении тестов я использовал swagger. Но спецификация API cайта довольно плохая, она не покрывает большое
количество плохих случаев.

Когда при написании теста на негативный сценарий я не находил спецификацию кода возврата, я добавлял в тест проверку,
что код возврата не 200 и не 500. Это разумное требование: сайт не должен возвращать, что всё хорошо, но и не должен
ломаться. Оказалось, что при некоторых запросах сайт всё-таки возвращает 500, что является ошибкой со стороны сайта.
Из-за этого некоторые тесты не проходят.

## Запуск

Сначала запустите приложение для заказа пиццы. Выполните из корня TestProject (https://github.com/NZRV-88/TestProject):

```shell
docker compose up -d --build app
```

Нужно дождаться полного запуска приложения.

Затем необходимо задать параметры окружения для тестов. Из корня этого проекта выполните:

```bash
cp .env.example .env
```

Если параметры TestProject отличаются от стандартных, поменяйте соответствующие параметры в `.env`. При этом перед
каждым тестом база данных очищается, поэтому не надо запускать тесты на production-сервере!

Для запуска тестов на компьютере должен быть установлен `npm`. Выполните из корня этого проекта:

```bash
npm ci
npm run test:report
npm run report:open
```
