# Домашнее задание 1

## Задача

Напишите две user story на любое выбранное приложение или сайт и опишите их критерии приемки.

## Ответ

Я разрабатываю собственное приложение, которое будет индексировать видео про лингвистику и показывать пользователям, какие слова обсуждались в эпизодах со ссылкой на точное время.

Сайт: https://mishkasimakov.github.io/words-unravelled/

### User story 1

Пользователь смотрит видео, авторы говорят, что слово Blōtmōnaþ обсуждалось в предыдущих эпизодах, и пользователь хочет найти и посмотреть это обсуждение.

Критерии приёмки:
1. На главной странице сайта видна поисковая строка без прокрутки и дополнительных действий
2. В поисковой строке можно набирать текст, при этом сразу же появляются результаты поиска под поисковой строкой.
3. Поиск работает, даже если пользователь допустил ошибки в слове. По запросу blotmonath или blodmonath должна выдаваться запись Blōtmōnaþ.
4. Записи отсортированы по точности совпадения с запросом
5. При нажатии на запись пользователь попадает на страницу этой записи. На ней написано название записи.
6. На странице записи отображаются все упоминания в эпизодах. Каждое упоминание содержит ссылку на видео с точным моментом времени, где эта запись обсуждается.

### User story 2

Пользователь хочет смотреть видео про лингвистику и видеть в реальном времени дополнительную информацию об обсуждаемых словах.

Критерии приёмки:
1. На сайте есть раздел со всеми эпизодами с канала про лингвистику. На этот раздел можно попасть с главной страницы сайта, нажав на ссылку вверху.
2. При нажатии на эпизод открывается страница этого эпизода.
3. На странице эпизода одновременно и без прокрутки виден плеер с видео и список обсуждаемых слов. Сам список слов может содержать прокрутку, если их много, при этом сверху должны быть слова, которые обсуждаются вначале. Каждое слово содержит ссылку на страницу этого слова и количетсво упоминаний в других эпизодах.
4. При нажатии на плеер включается видео эпизода на той же странице.
5. Когда авторы видео обсуждают какое-то слово, оно выделяется визуально. Если из-за прокрутки его было не видно на экране, то прокрутка автоматически листается до этого слова.
6. Если пользователь проматывает видео на другой момент времени, то выделенное слово указывает на слово, обсуждаемое в этот момент времени.
7. Рядом со словом должна быть кнопка, чтобы перемотать видео на момент времени, где это слово обсуждается.
8. Если пользователь листает список слов самостоятельно, то автоматическая прокрутка должна отключаться.
9. При нажатии на слово открывается страница этого слова, где видны все обсуждения этого слова в эпизодах.
